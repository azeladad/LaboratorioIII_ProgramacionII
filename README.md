## Descripción

Repositorio con la resolución de los 70 ejercicios del Laboratorio III, organizados en 3 niveles:

- **Nivel 1 — Fundamentos de Java + Excepciones** (25 ejercicios): manejo de excepciones con try-catch, finally, throw, y excepciones personalizadas.
- **Nivel 2 — POO Básica** (25 ejercicios): encapsulamiento, getters/setters, constructores y validaciones en las clases Persona, Cuenta, Producto, Estudiante y Empleado.
- **Nivel 3 — POO Avanzada** (20 ejercicios): herencia, polimorfismo, clases abstractas, e interfaces.

    cd N1_Ejercicios/N1_Ejercicio01

    java N1_Ejercicio01
